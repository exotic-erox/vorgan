# Theme

Colours are read from `~/.local/state/caelestia/scheme.json` and re-read about once a second, so changing the
wallpaper re-colours Vorgan live. Missing file means a built-in dark palette.

| Element | scheme key |
|---|---|
| Background | `surface` |
| Panels | `surfaceContainerLow`, `surfaceContainer`, `surfaceContainerHigh` |
| Selection, accent | `primaryContainer`, `primary` |
| Text, dim text | `onSurface`, `onSurfaceVariant` |
| Borders | `outlineVariant`, `outline` |
| Errors | `error` |
| Pins | `term3` |
| File kinds | `sapphire`, `tertiary`, `term2`, `term1`, `term13`, `term10`, `error`, `onSurface` |
