# Workflow

| Goal | Mouse | Keyboard |
|---|---|---|
| Go somewhere | Click, double-click, click the trail | `j k h l`, arrows |
| Jump far | Tab, click bubbles | `f` tags, `m`/`'` anchors, `~` frequent |
| Find | Filter box | `/` |
| Extract | Right-click, Extract Here / To... | `e` |
| Compress | Right-click, Compress To... | `z` |
| Move / copy | Drag onto a folder (ctrl = copy) | `x`/`y` then `p` |
| Quit and cd | | `q` (fish `vg` lands you there) |

## Build loop

1. Change code, run `pytest` (headless: keys, mouse, dialogs, archives, graph).
2. Install with `./install.sh`.
3. Try it in foot, report what feels wrong, repeat.
