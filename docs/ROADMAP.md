# Roadmap

Done in 0.1: browsing with 3 columns, full mouse support, Graph navigator with pinning, hint-jump, anchors, live filter,
hidden files, sort, multi-select, copy/cut/paste, rename, new, trash, delete, drag and drop, context menu, toolbar,
archives as folders, extract (here / to path / selected items, password prompt), compress (name, format, path, zip password),
previews (text with syntax colours, images as half-blocks, folders, archives), Caelestia theme live reload, fish `vg`, config file.

Next:
- Sixel preview for real pixels: dropped for now — Textual repaints erase overlapping sixel in foot,
  so the preview renders on the terminal's true pixel grid (TIOCGWINSZ cell size) instead.
- Recursive search across subfolders.
- Undo for trash and moves.
- Progress bars for long copies and extracts.
- AUR package.
- Graph look: smoother bubbles, themes per file type, animation on dive.
